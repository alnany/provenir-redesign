# Provenir.design Redesign — Maison

Static prototype (3 pages, self-contained HTML/CSS/vanilla JS). English only.

- `index.html` — landing page (full-bleed photographic hero)
- `world-wall.html` — World Wall feed (20 live posts, Latest/Popular sort, search filter)
- `product.html` — product detail (5-image gallery, keyboard accessible)
- `assets/` — editorial photography used in showroom cards / mechanism band

Design direction: "Maison" — photography-first editorial luxury for US/AU
designers & architects. Fraunces (light serif) + Inter + Spline Sans Mono.
Ink `#1A1714` / paper `#F2EEE7`, no accent color — monochrome + photography.
Product imagery hotlinked from public.provenir.design. All original site
content preserved (Chinese copy translated, manufacturer names romanized).

Dev notes: no build step — deploy as static files. Auth links currently point
at the live site; wire Log in / Sign up / Publish / Search / Connect to app routes.

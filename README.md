# Provenir.design Redesign — Black & Tan Gallery

Static prototype (3 pages, self-contained HTML/CSS/vanilla JS).

- `index.html` — landing page
- `world-wall.html` — World Wall feed (20 live posts, Latest/Popular sort)
- `product.html` — product detail (5-image gallery)
- `assets/` — generated showroom photography

Design direction: dark warm off-black ground + Chinese seal vermillion accent;
Bricolage Grotesque / Spline Sans Mono / Noto Serif SC. Product imagery hotlinked
from public.provenir.design. All original site content preserved.

Dev notes: no build step required — deploy as static files. Auth links currently
point at the live site; wire Log in / Sign up / Publish / Search to app routes.
